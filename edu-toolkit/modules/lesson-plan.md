# 教案生成模块

本模块生成符合中国 2022 版课标的完整教学设计，输出 Markdown + Word 双格式。

---

## 参考资料检索

在生成任何教学设计之前，必须按以下顺序检索参考材料：

### 第一步：查找课本内容（最高优先级）

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py references/课本内容/
```

如果找到匹配课题的 .md 文件，直接读取。生成时必须：
- 教材分析基于真实课本内容，不编造页码、例题编号
- 教学过程围绕课本的具体例题展开
- 巩固练习优先使用课本"做一做"原题
- `[图：描述]` 标注对应课本实际插图

如果没找到，提醒教师：

> ⚠️ 当前没有这个课题的课本内容。建议你把课本相关页面拍照发给我，我就能生成紧贴课本的教学设计。

没有课本内容时仍可生成，但不要编造具体的"第 XX 页""例 X"等细节。

### 第二步：查找教案参考和课标

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py references/教案参考/
python3 scripts/read_reference.py references/课标/
```

教案参考用于学习写法风格（目标粒度、提问具体程度、设计意图表述）。课标用于确保目标对齐、不超纲。

### 第三步：处理用户提供的材料

如果教师提供了额外文件（本地路径），用脚本处理：

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py "文件路径" --extract-images
```

脚本会提取文字并导出嵌入图片（自动过滤装饰性小图）。导出的图片用 Read 工具查看后补充描述。

## 生成前检查

### 课时范围判断

当教师提供课本照片、教材截图、扫描版 PDF 或课本内容整理稿时，**在持久化材料和生成教案之前**，必须先判断这批材料是否只适合生成 1 个课时，还是明显应拆成多个课时。不能默认把用户一次发来的所有页面合并成一份教案。

#### 必须判断是否拆分的线索

出现以下任一情况时，优先判断为"可能需要拆分"，并在继续生成前询问教师：

1. 材料中出现多个相对独立的活动、任务或板块，如"活动一/活动二/活动三""任务一/任务二/任务三""探究 1/探究 2/探究 3"。
2. 一个页面组同时包含新知探究、方案设计、统计整理、交流评价、拓展实践等多个完整学习任务，按 40 分钟课堂难以全部充分展开。
3. 页面跨度较大，或包含多个课题、多个知识点、多个例题、多个"做一做/练一练/练习"板块。
4. 教材本身标注"第 1 课时/第 2 课时""第一课时/第二课时"，或教师用书、目录、课件中提示该内容为多课时。
5. 综合与实践、项目化学习、单元整理复习等内容中，存在明显的"提出问题 - 探究实践 - 统计表达 - 展示评价"等可独立成课的阶段。

#### 询问方式

如果判断需要拆分，先给出简短判断和建议拆分方案，然后暂停生成，等待教师确认。不要先生成一份合并教案。

可直接使用以下提示：

> 我看这批课本内容不像只适合压成 1 个课时，更适合拆成 X 个课时：  
> 1. 第 1 课时：……  
> 2. 第 2 课时：……  
> 3. 第 3 课时：……  
>   
> 你希望我怎么生成？  
> - 按上面拆成 X 份教案  
> - 先生成第 1 课时  
> - 仍然合并成 1 份完整教案

如果只能初步判断但没有把握，也必须询问，不要擅自合并：

> 这几页内容可能跨多个课时，但我不确定你们实际课时安排。你希望按几个课时来备？如果没有固定安排，我可以先给一个拆分建议。

#### 不需要询问的情况

只有在材料明确只服务于一个课时，且用户已经给出"第 X 课时""就生成这一课时""合并生成一份"等明确指令时，才直接生成对应教案。

### 区分主线内容与练习材料

教师上传的课本页面中，可能同时包含例题、探究活动、做一做、练一练、课后练习、整理复习题、拓展题等内容。识别成功后必须先给材料做用途分类，不能把所有题目都当作本课教学过程的主线内容塞进教案。

#### 材料分类

整理课本材料时按以下类别标注：

1. **本课主线内容**：课题导入、情境图、例题、核心探究活动、课堂必须经历的操作或讨论。
2. **课堂巩固材料**：紧贴本课目标的"做一做""试一试""练一练"中的代表性题目，可少量选入教学过程。
3. **课后/备选练习**：成组编号练习、综合练习、拓展题、复习题、整页练习册式题目，一般不全部进入教学过程。
4. **跨课时材料**：与当前课时目标相关但明显属于后续活动、统计整理、展示评价或拓展实践的内容。

#### 使用规则

生成教案时必须遵守：

- 教学过程优先围绕"本课主线内容"展开。
- "做一做/练一练"只选与本课目标最贴近的 1-3 个代表性题目用于巩固，不要把 1、2、3、4、5、6、7、8、9 等整组练习逐题写入课堂流程。
- 成组练习题如果数量较多，应放入"作业设计"或"备选练习建议"，并说明可根据课堂时间选用。
- 如果上传页面主要是练习页，而不是新授课页面，先询问教师：是要基于这些练习生成"练习讲评/复习课教案"，还是要使用出题模块生成分层练习。
- 如果某些练习题属于后续课时或复习拓展，持久化时可以保留原文，但生成当前课时教案时不得强行纳入。

整理课本内容参考稿时，建议保留以下小标题：

```markdown
## 本课主线内容
## 课堂巩固材料
## 课后/备选练习
## 可能跨课时的内容
```

## 输入规范

### 必填信息

用户需提供以下三项基本信息：

1. **学科**：语文、数学、英语、科学、道德与法治、音乐、美术、体育等
2. **年级**：一年级至九年级（或高一至高三）
3. **课题**：具体课题名称（如"两位数乘两位数"、"春天的故事"）

### 可选信息

如用户提供以下信息，应融入教学设计：

- 课标要求：具体课程标准条目
- 学情说明：学生已有基础、常见困难
- 课时安排：本课为第几课时，共几课时
- 教材版本：人教版、北师大版、苏教版等
- 特殊要求：信息技术融合、小组合作、项目式学习等

### 信息不足时的处理

如用户只给了课题没给年级学科，先追问确认，不要猜测。例如：

> 请确认：这是哪个年级、哪个学科的课？如果有教材版本偏好也请告知。

## 输出格式

生成一份完整的教学设计文档，结构如下。**必须严格遵循此结构，不得省略任何板块。**

```markdown
# 《课题名称》教学设计

（学校/作者：仅在用户明确提供且允许保留时填写；否则省略）

## 【教学内容】

（只写已确认信息。若教材版本、年级册次或页码未确认，可写"围绕《课题名称》相关内容展开"，不要补写"XXX版""X年级X册""第XX页"。）

## 【教材分析】

（包含以下要素，整合为 2-3 段连贯文字：）
- 本课在单元/教材中的位置和承上启下关系
- 引用《义务教育XX课程标准（2022年版）》对本内容的"学业要求"原文
- 教材的编排意图和设计思路
- 本课的核心数学思想/学科思想

## 【学情分析】

（包含以下要素：）
- 学生已有的知识基础和经验
- 学生可能存在的认知困难或典型误区
- 本课如何在已有基础上推进

## 【主要设计思路】

（一句话概括本课的教学理念和核心策略）

## 【教学目标】

（融合式素养目标，不分"知识与技能/过程与方法/情感态度"三维。每条目标 = 可观测的学习行为 + 素养指向。通常 2-4 条。）

1. （行为描述），发展/提升XX（核心素养名称）。
2. 在（过程/活动）中，（行为描述），发展XX（核心素养名称）。
3. 在（活动）中，感受……，增强……。

## 【教学重点】

（本课核心知识/技能，学生必须掌握的内容）

## 【教学难点】

（学生理解或操作上容易出错的地方）

## 【教学过程】

（用表格呈现，每个环节占一行或多行。师生活动列中包含具体的教师行为、学生活动和【设计意图】。在需要配图的地方用"[图：描述]"标注，如"[图：点子图 14×12]""[图：竖式计算过程]""[图：学生操作学具示意]"。）

| 教学环节 | 目标指向 | 师生活动 | 评价关注点 |
| --- | --- | --- | --- |
| 一、情境导入（约 5 分钟） | 指向目标 X：简要说明本环节与目标的关系 | **教师活动：**（具体行为、关键提问）[图：情境图/实物图描述] **学生活动：**（预期反应和参与方式）**【设计意图】**（为什么这样设计） | （学生应表现出的可观测行为） |
| 二、探究新知（约 20 分钟） | 指向目标 X、X：…… | **活动一：……** **教师活动：**……[图：操作示意/板书示意] **学生活动：**…… **【设计意图】**…… **活动二：……** …… | …… |
| 三、巩固练习（约 10 分钟） | 指向目标 X：…… | **教师活动：**（出示具体题目）**学生活动：**…… **【设计意图】**…… | …… |
| 四、课堂小结（约 3 分钟） | | **教师活动：**（引导回顾的具体提问）**学生活动：**…… | …… |

## 【板书设计】

（用文本框或简图呈现板书布局）

## 【作业设计】

1. （基础巩固类）
2. （拓展应用类，可选做）

## 【教学反思】（课后填写）

- 本课教学目标是否达成？依据是什么？
- 学生在哪些环节理解困难？如何调整？
- 下次再教这课，会做什么改变？
```

## 教学目标撰写规则（2022 新课标）

教学目标是本教学设计中最重要的部分，**必须严格遵循以下规则**：

### 基本原则

1. **不得使用旧的三维目标分类**：不分"知识与技能""过程与方法""情感态度与价值观"三块，而是融合为每条目标同时包含行为、过程和素养指向。
2. **学生为主语**：不写"使学生……""让学生……""培养学生……"，直接以学生的行为开头，如"能说出……""通过……理解……"。
3. **行为可观测**：不写"了解""知道""认识到"等模糊动词，改用"说出""列举""计算""比较""画出""用……表示""解释……的道理"等可观察、可检测的行为动词。
4. **素养指向明确**：每条目标末尾必须指明发展哪个核心素养，如"发展运算能力""培养几何直观""增强应用意识"。

### 小学数学核心素养（2022版课标）

生成数学教学设计时，教学目标的素养指向必须从以下 11 个核心素养中选取（不可自造）：

| 核心素养 | 适用场景 | 典型行为动词 |
| --- | --- | --- |
| 数感 | 数的认识、大小比较、估算 | 感悟、估计、判断、说出……大约是多少 |
| 量感 | 长度、面积、体积、质量、时间等度量 | 感受、估测、选择合适的单位 |
| 符号意识 | 用字母表示数、等式、不等式 | 用符号表示、写出等量关系 |
| 运算能力 | 加减乘除计算、算理理解 | 计算、说出每一步的道理、验算 |
| 几何直观 | 用图形描述问题、数形结合 | 画图表示、借助图形说明、对照图和式 |
| 空间观念 | 图形认识、位置关系、变换 | 辨认、描述位置、想象变换后的样子 |
| 推理意识 | 规律发现、归纳、类比、演绎 | 发现规律、说出理由、类比迁移 |
| 数据意识 | 统计、概率、数据收集与分析 | 收集数据、用图表表示、作出判断 |
| 模型意识 | 用数学描述现实问题 | 列出算式、建立等量关系、用模型解释 |
| 应用意识 | 解决真实情境问题 | 在……情境中解决、说出数学与生活的联系 |
| 创新意识 | 提出新方法、一题多解、开放性问题 | 提出不同方法、独立思考、说出自己的想法 |

### 目标写法示例

**正确写法（融合式素养目标）：**

```
1. 能说出千以内数的组成，能用计数器、"板、条、块"模型、算盘等多种形式
   表示千以内的数，提升数形结合能力与模型意识。
2. 在操作学具的过程中进一步了解位值概念，知道数字在不同数位上表示不同
   的数值，学会区分板、条、块的不同含义，发展数感。
3. 在动手实践中，感受数学学习的乐趣，增强学习数学的自信心。
```

**错误写法（旧三维目标，禁止使用）：**

```
知识与技能：学生能够认、读、写千以内的数。
过程与方法：通过操作学具，学会用多种方式表示数。
情感态度与价值观：在学习过程中感受数学的乐趣。
```

### 其他学科的核心素养

如果生成的是非数学学科的教学设计，教学目标同样采用融合式写法，素养指向参考对应学科的 2022 版课程标准。例如：
- **语文**：文化自信、语言运用、思维能力、审美创造
- **英语**：语言能力、文化意识、思维品质、学习能力
- **科学**：科学观念、科学思维、探究实践、态度责任
- **道德与法治**：政治认同、道德修养、法治观念、健全人格、责任意识

## 教学过程撰写规则

### 表格格式要求

1. **必须用表格**：教学过程用 4 列表格呈现（教学环节 | 目标指向 | 师生活动 | 评价关注点），不用叙述式。
2. **目标指向**：每个环节必须标注"指向目标 X"，说明本环节对应哪条教学目标。
3. **师生活动**：在同一个单元格内分别写"教师活动""学生活动"和"【设计意图】"，内容要具体。
4. **评价关注点**：写明学生在本环节应表现出的可观测行为，供教师巡视和课后反思参考。
5. **配图标注**：在需要配图的地方用 `[图：描述]` 标注。描述要具体，如 `[图：14×12 的点子图，用虚线分成 14×10 和 14×2 两部分]`、`[图：竖式计算过程，标注每一步的含义]`、`[图：学生用小方块拼面积的操作示意]`。

### 内容要求

1. **教学过程必须具体**：不写"教师讲解知识点"，要写出具体讲什么、怎么讲、问什么问题。
2. **时间分配必须合理**：一节课 40 分钟（小学）或 45 分钟（初高中），各环节时间之和不能超。
3. **设计意图不是套话**：每个环节的设计意图要说清楚"为什么这样做"，不写"激发兴趣""培养能力"之类的泛泛表述。
4. **关键提问要写出来**：新授环节中教师的核心提问必须明确写出，不能只写"教师提问引导"。
5. **例题练习题要具体**：给出完整题目内容，不要写"出示例题"然后留空。
6. **符合学段特征**：低年级用游戏化、直观操作；高年级用探究、讨论、归纳。

## 注意事项

- 不要生成与 2022 版课标明显不符的内容（如一年级教乘法、三年级教方程）。
- 教材分析中必须引用 2022 版课标的"学业要求"或"内容要求"原文，不可编造课标条文。如果不确定具体条文，写出课标对该学段该领域的一般性要求即可。
- 教学内容、教材分析、标题和文件名中的年级、学科、上册/下册如果能确认，应保留；教材版本、出版社、页码必须有明确来源才写。不确定时省略或写"未确认"，不要根据课题、常见教材或相似参考材料推断。
- 学校、作者、执教教师等个人或单位信息默认不写；只有用户明确要求保留时才写入生成文档。
- 如果用户提供了学情说明，教学设计必须体现对学情的回应。
- 板书设计用简洁的文本表示即可，不需要复杂图形。
- `[图：描述]` 标注是给教师的配图建议，提示该位置适合放什么样的课件图片或学具照片。

## 输出与文件保存

### 默认流程（Markdown + Word 双输出）

1. **先生成 Markdown**：按上述格式生成完整教学设计内容。
2. **保存 .md 文件**：用 Write 工具保存为 `{课题}_教学设计.md`，保存到当前工作目录。
3. **生成 Word 文档**：调用本 Skill 自带的转换脚本：

```bash
cd "$SKILL_ROOT"
python3 scripts/to_docx_lesson.py "{课题}_教学设计.md" "{课题}_教学设计.docx"
```

脚本使用 python-docx 库（纯 Python，无需 .NET 环境）。共享 Skill 中不要硬编码某台机器的 Python 绝对路径；如果本地环境遇到依赖或代码签名问题，应在本机运行时临时指定已验证可用的解释器。

### Word 文档格式规范

生成的 .docx 文件遵循以下排版规范：
- 页面：A4，页边距上下 2.54cm、左右 3.17cm
- 标题：黑体，一级标题小二号(22pt)居中，二级标题三号(16pt)，三级标题四号(14pt)
- 正文：宋体小四号(12pt)
- 表格：带边框网格线，宋体五号(11pt)
- 列表：标准项目符号样式

### 仅输出 Markdown 的情况

如果用户明确说"不需要 Word"，则只输出 .md 文件即可。

## 生成完成后的对话提示

每次生成完成后，都要在**对话中**（不要写在生成的文档里）附上以下提示：

> 💡 你可以发给我这些材料来提升生成质量：
>
> 1. **课本页面**（最重要）——把这节课对应的课本页面拍照发给我，我就能生成紧贴课本的教学设计，例题、做一做、情境图都会和你手上的课本一致
> 2. **你觉得写得好的教案**——Word、PDF、纯文本都行，我会学习里面的风格和深度
> 3. **教师用书或课标**——比如教师用书的教材分析、课程标准的相关章节
>
> 直接把文件发给我就行，我会自动归类保存好，下次生成时参考。

如果 `references/课本内容/` 目录中没有匹配当前课题的内容，优先提示课本内容缺失（见第一步中的提醒），然后再根据情况补充：

如果 `references/教案参考/` 目录也为空或没有匹配当前学科的参考：

> ⚠️ 当前还没有该学科的教案参考，生成结果是基于通用规范的。如果你手上有写得好的教案，发给我就能显著提升下次的生成质量。

### 与分层练习模块的联动

如果当前对话中教师刚生成了一份教学设计，可以在提示中补充一句：

> 📝 需要配套的分层练习题吗？直接告诉我知识点和题量就行。
