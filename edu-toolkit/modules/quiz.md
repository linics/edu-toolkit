# 分层练习生成模块

本模块生成双页分层作业（A 页给需要巩固的学生，B 页给掌握较好的学生），输出学生版 + 教师版双文件，Markdown + Word 双格式。

---

## 参考资料检索

在生成任何练习之前，必须先执行以下检索步骤：

### 第一步：查找相关练习参考

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py references/练习参考/
```

只读取已经确认可靠的真实参考。匹配优先级：
1. 同学科 + 同年级 + 相近知识点（最佳匹配）
2. 同学科 + 相近年级，且题型风格确实相关（次优）

不要使用"同学科任意参考"兜底；如果没有贴近当前任务且来源可靠的参考，就跳过，直接遵守本模块的输出格式。

找到匹配文件后读取内容，重点学习：
- 题目的难度梯度如何安排
- 情境包装的自然程度
- 易错题的设计思路（针对什么真实误区）
- 答案解析的详略程度
- 教师使用建议的实用性

即使读取了真实参考，也只参考题目质量和教学思路，不复制其文档结构。最终输出必须遵守"学生作业版严格两页 + 教师答案版单独保存"的格式。

### 第二步：查找课标与课本内容

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py references/课本内容/
python3 scripts/read_reference.py references/课标/
```

如果找到相关文件，确保生成的练习：
- 题目内容贴合课本例题、教材练习和当前课题范围
- 题目难度和数值范围符合学段要求
- 不出现超纲内容
- 情境设计符合学生认知水平

### 第三步：查找用户提供的本地材料

如果用户提供了额外参考（如"参考这份练习""按这个难度出""看看这本练习册"）：

```bash
cd "$SKILL_ROOT"
python3 scripts/read_reference.py "/用户提供的文件.docx"
```

支持 Word、PDF、文本、图片等各种格式。

## 生成前检查

### 出题范围判断

当教师提供课本照片、教材截图、扫描版 PDF、练习页、试卷或练习册页面时，**在持久化材料和生成练习之前**，必须先判断这批材料对应的是单一知识点/单一课时，还是跨多个知识点、多个课时或整个单元。不能默认把用户一次发来的所有页面混成一套分层练习。

#### 必须判断是否拆分的线索

出现以下任一情况时，优先判断为"可能需要拆分"，并在继续生成前询问教师：

1. 材料中出现多个相对独立的知识点、例题、活动或题组，如"活动一/活动二/活动三""练习 1/练习 2""第 1 课时/第 2 课时"。
2. 页面同时覆盖新知探究、基础练习、综合应用、拓展实践、单元复习等不同用途。
3. 题目编号很多，且题型或考查点跨度明显，如 1-9 题分别考查多个概念、多个运算类型或多个文本技能。
4. 教材目录、页眉、课题或题干提示材料来自多个小节、多个课题、整理复习或单元综合练习。
5. 综合与实践、项目化学习、整单元复习材料中，存在可独立出题的阶段或任务。

#### 询问方式

如果判断需要拆分，先给出简短判断和建议拆分方案，然后暂停生成，等待教师确认。不要先生成一套混合练习。

可直接使用以下提示：

> 我看这批材料可能不适合直接混成一套分层练习，更适合按范围拆开：  
> 1. 范围 1：……  
> 2. 范围 2：……  
> 3. 范围 3：……  
>   
> 你希望我怎么生成？  
> - 按上面拆成多套练习  
> - 先生成第 1 个范围  
> - 仍然合并成一套综合练习

如果只能初步判断但没有把握，也必须询问，不要擅自合并：

> 这些材料可能跨多个知识点/课时，但我不确定你实际想练哪一块。你希望按哪个知识点或课时生成？如果没有固定范围，我可以先给一个拆分建议。

#### 不需要询问的情况

只有在材料明确只服务于一个知识点/课时，或用户已经明确说"整页都用""合并成一套综合练习""按这个单元复习生成"等，才直接生成对应练习。

### 区分原题用途

教师上传的材料中，可能同时包含课本例题、做一做、练一练、课后练习、试卷原题、错题、拓展题等。识别成功后必须先给材料做用途分类，不能把所有题目都当作必须覆盖的出题范围，也不能无提示地照搬整页原题。

#### 材料分类

整理参考材料时按以下类别标注：

1. **核心出题依据**：本次要练的知识点、例题、核心方法、关键图形或文本。
2. **题型风格参考**：可学习题型、难度梯度、情境包装、设问方式，但不逐题照搬。
3. **可选巩固原题**：紧贴本次知识点的"做一做/练一练"代表题，可少量改编或作为同类题依据。
4. **课后/综合/拓展题**：成组编号练习、综合题、拓展题、复习题，通常只作为难度或题型参考。
5. **跨范围题目**：与当前知识点不完全一致、属于后续课时或单元复习的题目。

#### 使用规则

生成分层练习时必须遵守：

- 两页作业都应围绕本次确认的知识点/课时展开，A 页面向需要巩固的学生，B 页面向掌握较好的学生。
- 每一页内部都必须有由易到难的梯度，不要把 A 页做成纯基础题、B 页做成纯提高题。
- 题量以用户要求为准；用户没要求时默认每页 6 题。若多为填空、判断、选择等短答题，可提高到每页 8 题；不要因为图片上有 1-9 题就默认生成或覆盖全部 1-9 题。
- "做一做/练一练/课后练习"只选与本次知识点最贴近的代表题作为题型依据，不要把整组题逐题搬进新练习。
- 如果教师明确要求"照着这些原题讲评/改编/仿写"，要说明当前输出是讲评、改编还是仿写；除非用户明确要原题，否则避免原样复制整页题目。
- 如果上传页面主要是试卷或成套练习，先询问教师：是要生成同类分层练习、练习讲评，还是错题变式。
- 如果某些题目属于后续课时或综合复习，持久化时可以保留原文，但生成当前练习时不得强行纳入。

整理参考材料时，建议保留以下小标题：

```markdown
## 核心出题依据
## 题型风格参考
## 可选巩固原题
## 课后/综合/拓展题
## 跨范围题目
```

## 输入规范

### 必填信息

1. **年级**：一年级至九年级（或高一至高三）
2. **知识点**：具体知识点（如"两位数加两位数进位加法"、"面积计算"、"比喻句"）
3. **页内题量**：每页题量或总题量。未说明时默认每页 6 题，共两页；多为短答题（填空、判断、选择）时可提高到每页 8 题；含较大图表、长阅读材料、较多计算过程或开放表达题时可降到每页 5 题。

### 可选信息

- **难度偏好**：偏基础 / 均衡 / 偏拓展
- **情境主题**：将题目包装在某个生活情境中（如"春游购物"、"运动会"）
- **题型要求**：填空、选择、判断、应用题、简答等
- **学生分层画像**：如"A 页给基础薄弱学生，B 页给学有余力学生"
- **特殊约束**：数值范围、是否含进退位、是否含小数等

### 信息不足时的处理

至少需要知道年级和知识点。如用户只说"帮我出几道题"，追问：

> 请告诉我：哪个年级、什么知识点？如果没有特别要求，我会默认生成两页分层作业，每页 6 题，A 页给需要巩固的同学，B 页给掌握较好的同学。

## 输出格式

默认输出分为两份：

1. **学生作业版**：严格 2 页（A 页给需要巩固的学生，B 页给掌握较好的学生）。学生版只放题目和必要图表，不放年级、知识点、适用对象、页内梯度、教师说明、参考答案和教师建议。
2. **教师答案版**：单独保存参考答案、考查点、难度说明和使用建议。

## 质量要求

1. **答案必须正确**：每道题必须验算/验证答案，数学题尤其注意计算准确性。不要依赖心算——生成教师版答案后，必须用 Bash 工具跑 `python3 -c` 对所有数值型答案做一次计算验证（见"输出与文件保存"中的验算步骤）。
2. **双页分层清晰**：A 页面向需要巩固的学生，B 页面向掌握较好的学生；两页不能只是题目数量不同，必须体现学习对象差异。
3. **页内梯度清晰**：每一页内部都要从易到难。A 页也要有小综合，B 页也要有快速巩固，避免"一页全基础、一页全难题"。
4. **题目必须具体完整**：不写"类似的题目"或"同类型练习"，每道题都给出完整题干。
5. **情境自然不牵强**：如果加了情境包装，情境要合理，不能为了包装而让题目变得难以理解。
6. **符合学段认知**：
   - 低年级（1-2 年级）：数字范围小、语言简单、图文结合
   - 中年级（3-4 年级）：适当增加文字量、引入简单情境
   - 高年级（5-6 年级）：综合性增强、情境复杂度提升
   - 初中以上：抽象思维、多步推理、开放性问题
7. **易错题要有教学价值**：不是故意出怪题，而是针对真实的学生认知困难点。
8. **学生版严格两页且留白舒展**：不要为了塞满页面压缩字号、行距或作答空间。
9. **两页都能独立使用**：每页都应包含必要题干、题号和完成目标，不能要求学生依赖另一页才能完成。
10. **可读性优先**：默认每页 6 题；短答题（填空、判断、选择）为主时可提高到每页 8 题；题干较长、包含阅读材料、SVG 图表、计算过程或开放表达题时，降到每页 5 题。优先保证学生拿到纸面后读得清楚、写得开。
11. **作答空间要匹配题型**：填空、选择、判断等短答题不额外留大空间；计算题、画图题、说明理由题、开放题必须预留合适空间。

## 学科适配说明

### 数学

- A 页侧重概念辨析、基本计算、方法巩固和典型易错
- B 页侧重变式应用、综合问题、逆向思维或一题多解
- 两页内部都要保留从易到难的顺序
- 必须验算所有答案

### 语文

- A 页侧重字词、句式、基础阅读理解和典型误区
- B 页侧重迁移阅读、仿写、表达和开放性思考
- 两页内部都要保留从识记/理解到运用/表达的顺序
- 注意区分识记类和运用类

### 英语

- A 页侧重词汇、句型、基础语法和易错辨析
- B 页侧重情境对话、短文理解、表达迁移或写作
- 两页内部都要保留从输入理解到输出运用的顺序
- 注意词汇量控制在学段范围内

### 其他学科

- 根据学科特点调整题型（如科学侧重实验设计、历史侧重史料分析）
- 保持"两页分层 + 页内梯度"的基本结构

## 注意事项

- 数学计算题：不要靠心算，必须在验算步骤中用代码确认（见下方"答案验算"）。
- 不要出超纲内容：一年级不出乘除法，三年级不出方程。
- 每页题目编号从 1 开始，格式统一。
- 如果用户要求特定分配（如"A 页 8 题、B 页 6 题"或"A 页偏基础、B 页偏拓展"），按用户要求分配。
- 默认结构：A 页侧重概念理解、直接运用、典型基础错误；B 页侧重变式应用、错因诊断、符号化表达和迁移编题。
- 学生作业版 Markdown 中两页之间必须加入 `<!-- pagebreak -->`，确保 Word 输出时分页。
- 为保证学生版实际可打印为 2 页且不显得局促，题干应简洁，少用长段背景；如果题目文字较长，应主动减少题量，不压缩字号和间距换取题量。
- 学生版可以使用作答空间标记，转换 Word 时会渲染为空白作答区：
  - `{{space:short}}`：短答/一句理由，约 1 行空间
  - `{{space:calc}}`：计算过程，约 2 行空间
  - `{{space:explain}}`：说明理由/综合题，约 3 行空间
  - `{{space:draw}}`：画图/表格/较长开放题，约 4 行空间
- 生成时要主动判断每道题需要多少作答空间，并据此调整题量。不能只为了塞满 6 题而不给计算题留过程空间。
- 如果一页中计算题、画图题、说明题较多，应降低题量；如果多为填空/选择/判断题，可以提高题量。

### 篇幅预算硬约束

学生版必须按 A4 打印效果控制为严格 2 页，A 页和 B 页各 1 页。题量不是硬塞出来的，题目数量必须服从纸面容量。

每页容量参考：

- 短答题（填空、选择、判断、直接写结果）：每题约 1-2 行。
- 普通计算题：题干 1 行 + `{{space:calc}}`，每题约 3-4 行。
- 说明理由题：题干 1-2 行 + `{{space:explain}}`，每题约 4-5 行。
- 画图、表格、开放表达题：题干 + `{{space:draw}}`，每题约 5-6 行，通常每页最多 1 题。

生成时先估算每页空间：

1. 默认每页 6 题只适合短答题和少量计算题混合。
2. 如果一页中有 3 题及以上需要 `{{space:calc}}`，通常降到 5 题。
3. 如果一页中有 2 题及以上需要 `{{space:explain}}` 或 `{{space:draw}}`，通常降到 4-5 题。
4. 不要在同一道大题里堆多个需要独立作答空间的小题；确需小题时，控制为 2-3 个短小项目，或拆成独立题号并减少总题量。
5. 题干背景超过 2 行时，优先压缩情境文字或减少题量，不用缩小字号、挤行距、减少留白来保住题数。

生成 Word 后必须检查实际页数：学生版应为 2 页，且 A 页和 B 页都不能跨页。如果超页，先删减题量、缩短题干或降低作答空间密度，再重新生成。

### 竖式题排版规则

不要在 Markdown 中用空格、横线、括号、竖线或代码块拼除法竖式、乘法竖式等版式。纯文本竖式在 Markdown 和 Word 转换后容易错位，尤其是除法竖式。

可用写法：

- 计算题只写横式，如 `536 ÷ 3 =`，后面用 `{{space:calc}}` 留给学生自己写竖式。
- 判断正误题只写横式和结果，如 `624 ÷ 6 = 104`，让学生判断并说明理由。
- 需要考查竖式结构时，用文字描述任务，如"请先估一估商是几位数，再用竖式计算并验算"。
- 教师答案版可以用步骤文字说明，不用在 Markdown 中画竖式。

## 输出与文件保存

### 默认流程（学生版 + 教师版）

1. **先生成学生作业 Markdown**：按上述"学生作业版"格式生成严格两页的作业正文。
2. **保存学生作业 .md 文件**：用 Write 工具保存为 `{知识点}_分层作业_学生版.md`，保存到当前工作目录。
3. **生成学生作业 Word 文档**：调用本 Skill 自带的转换脚本：

```bash
cd "$SKILL_ROOT"
python3 scripts/to_docx_quiz.py "{知识点}_分层作业_学生版.md" "{知识点}_分层作业_学生版.docx"
```

4. **再生成教师答案 Markdown**：按上述"教师答案版"格式生成答案、考查点和使用建议。
5. **保存教师答案 .md 文件**：用 Write 工具保存为 `{知识点}_分层作业_教师版.md`。
6. **答案验算（数学等计算类学科必做）**：用 Bash 工具运行 `python3 -c "..."` ，把教师版中每道有数值答案的题目的算式和期望结果逐一验算。示例：

```bash
python3 -c "
checks = [
    ('A-1', 12*23, 276),
    ('A-2', 21*13, 273),
    ('B-3', 486//18, 27),
    # ... 把所有数值型题目列在这里
]
for label, computed, expected in checks:
    status = '✓' if computed == expected else '✗'
    print(f'  {status} {label}: 计算={computed}, 答案={expected}')
errors = [c for c in checks if c[1] != c[2]]
print(f'验算完成: {len(checks)}题, 错误{len(errors)}题')
if errors:
    print('请修正以上错误后再继续！')
"
```

   验算范围包括：四则运算、分数加减乘除、大小比较（用 `from fractions import Fraction`）、面积/周长/单位换算等。如有错误，先修正教师版和学生版的 .md 文件，再继续。

脚本使用 python-docx 库（纯 Python，无需 .NET 环境）。共享 Skill 中不要硬编码某台机器的 Python 绝对路径；如果本地环境遇到依赖或代码签名问题，应在本机运行时临时指定已验证可用的解释器。

### Word 文档格式规范

生成的 .docx 文件遵循以下排版规范：
- 页面：A4，学生作业版采用适中页边距（上下约 1.6cm、左右约 1.9cm），优先保证可读性和作答空间
- 标题：黑体，学生版标题简短居中，不使用多级说明性标题
- 题目正文：宋体 12pt 左右，段落间距适中，不使用过度压缩的行距
- 作答空间：根据 `{{space:...}}` 标记渲染为横线区域
- 答案表格：带边框网格线，宋体 11-11.5pt
- 列表：标准编号样式

### 仅输出 Markdown 的情况
